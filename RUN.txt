ubuntukit - paste-and-run (no editing)

OPTION A - each machine gets its own onion (run INSIDE each Ubuntu VM, Proxmox console):
  curl -fsSL https://raw.githubusercontent.com/Catgirlmp3/ubuntukit/main/setup-tor-ssh.sh -o setup-tor-ssh.sh
  sudo bash setup-tor-ssh.sh
  sudo cat /var/lib/tor/ssh_hidden_service/hostname
  Keys auto-fetch from https://github.com/Catgirlmp3.keys

OPTION B - one onion for all machines (run ONCE on gateway .1, re-run after adding .5/.6):
  curl -fsSL https://raw.githubusercontent.com/Catgirlmp3/ubuntukit/main/setup-tor-gateway.sh -o setup-tor-gateway.sh
  sudo bash setup-tor-gateway.sh
  sudo cat /var/lib/tor/proxmox_gateway/hostname
  Existing :8006 mapping is kept. New SSH hosts get next free port 2221, 2222...

REMOTE BOOTSTRAP (away from home, single onion, your flow):
  1. PC: Tor Browser open + PuTTY tunnel -> 127.0.0.1:8006 -> primary Proxmox web (existing).
  2. Windows VM browser: http://172.16.3.2:8006 (then .3, .4) -> target Proxmox -> Shell.
  3. In target Shell, paste (enables SSH + keys, no editing):
       curl -fsSL https://raw.githubusercontent.com/Catgirlmp3/ubuntukit/main/setup-tor-ssh.sh -o setup-tor-ssh.sh
       sudo bash setup-tor-ssh.sh
  4. Back on .1 Shell, re-run: sudo bash setup-tor-gateway.sh
     (picks up the new box as next free port 2222/2223..., keeps :8006).
  5. PC PuTTY direct: Host=iujzltzy6mdr6c5dzh3fps2vakd2isqr35cxx2y75ba57vlnlkndaxad.onion Port=2222 (.2) etc.

VERIFY (on server):
  systemctl is-active tor ssh ubuntukit
  sudo journalctl -u ubuntukit -n 20 --no-pager
  Proxmox web -> VM Options -> Start at boot = Yes

  2. PuTTY > Connection > Proxy > SOCKS5, 127.0.0.1, 9150, DNS at proxy = Yes
  3. PuTTY > Session > Host = iujzltzy6mdr6c5dzh3fps2vakd2isqr35cxx2y75ba57vlnlkndaxad.onion
     Port = 22 (Option A, per-machine onion) or 2221/2222/2223/2224 (Option B, gateway above)
  4. SSH > Auth > your .ppk key > Open
